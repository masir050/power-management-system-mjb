# 评测报告 · 100 题

> 数据采集：2026-11-12，power-rag 模块，`/eval?mode=rrf-rerank` + `/ask` 端到端。
> 语料：`data/docs/` 15 份规程 → 180 个知识块（每份 12 节）。
> 原始数据：`eval-raw-100.json`（100 题检索明细）、`answer-sample-30.json`（30 条答案原文）。

## 一、结论

| 指标 | 结果 | 测法 |
|---|---|---|
| 检索 Top-3 命中 | **100.0%**（70 / 70） | 100 题全量，否定题不计入命中分母 |
| 检索 Top-1 命中 | **97.1%**（68 / 70） | 同上 |
| 答案正确率 | **100.0%**（30 / 30） | 人工抽检 30 条（直答 15 + 跨段 15） |
| 否定类拒答准确 | **100.0%**（30 / 30） | 30 条否定题全量，重排分 < 0.5 即拒答 |
| 平均响应 | **1.47 s** | 30 条样本，`/ask` 端到端（含检索 + 大模型） |
| 单次 token | **832**（prompt 745 / completion 87） | `/stats` 前后差值 24969 ÷ 30 |

三条判定标准（先定标准再判，避免"看着差不多就算对"）：

1. **结论对**：答案里的数字/等级/顺序与规程原文一致，且回答了问题本身；
2. **依据对得上来源**：答案标注的「资料 N」确实包含那句话，不是从别的块拼的；
3. **没编造数字**：出现原文没有的数值、时限、设备名，一律判错。

第 3 条本次逐条回查过语料：95℃、198–242V、1.5m、70%、20 次、25mm²、25kΩ、300MΩ、±5%、0.8%、5μL/L、100pC、0.55/0.50/0.45MPa、60% 等阈值均在原文中找得到出处。

## 二、题库构成

| 类型 | 数量 | 覆盖 | 出题口径 |
|---|---|---|---|
| 直答 | 40 | 15 份规程全覆盖（每份 2–6 题） | 答案落在单一小节，问法换同义词，不抄原文 |
| 跨段 | 30 | 同上 | 需要两节拼起来（如「96℃ + 冷却器全停 25 分钟」要同时用分级表和冷却器条款） |
| 否定 | 30 | 同领域但库里确实没有 | 换流站阀厅、GIS 气室、消防水带口径、接地扁铁镀锌层…不是「今天星期几」这种离谱题 |

文件：`data/eval/questions.csv`，三列 `问题,期望出处,类型`。
否定题的期望出处写 `NONE`，评测接口据此把它们从命中率分母里剔除。

> 题库随语料一起修过一轮：语料扩充后，原本 4 道「库里没有」的否定题变成了有答案（如"有载调压油多久换"），
> 已换成语料确实没写、但同领域的题；另有 1 道题的措辞改回规程原话（"不得超过出厂值的 1.2 倍"→问"不能超过多少倍"）。

## 三、复现方式

```bash
# 1. 起服务后跑检索评测（不调大模型，只算检索与拒答）
curl "http://localhost:8088/eval?mode=rrf-rerank"

# 2. 答案抽样：/ask 走完整链路，前后对 /stats 取差值
curl "http://localhost:8088/stats/reset"
curl "http://localhost:8088/ask?q=油温到多少度算危急缺陷"
curl "http://localhost:8088/stats"
```

前置条件：`pgv`（pgvector，180 块）、`power-redis`、`neo4j` 三个容器在跑；`data/docs/` 15 份 md 已灌库。
换机器复现前先确认 `vector_store` 里是 180 行，否则分母不对、数字没意义。
抽检前记得清 `ans:*` 缓存键，否则第二次问同一句会命中缓存、耗时变成 5 毫秒。

## 四、检索结果明细

### 4.1 Top-1 没中的两题（Top-3 里都在）

| 问题 | 期望 | 实际 Top-1 | 重排分 |
|---|---|---|---|
| 开关跳闸后录波啥时候调取，先看什么 | 故障录波分析导则 | 开关跳闸分析导则 | 0.794 |
| 断路器回路电阻实测值不能超过出厂值的多少倍 | 断路器检修导则 | 绝缘降低原因与处理 | 0.564 |

第一题是真·跨文档：问句前半"开关跳闸后"天然贴《开关跳闸分析导则》第 2 节（那节确实在讲跳闸后先看什么），
后半"录波调取"才是《故障录波分析导则》的内容。两份文档都在 Top-3，抽检时答案把两边的条款拼全了。

第二题两个块都含「回路电阻」相关表述：《断路器检修导则》给的是"实测值不得超过出厂值的 1.2 倍"，
《绝缘降低原因与处理》讲的是触头接触电阻升高的成因，重排更认后者。答案仍取到了 1.2 倍这个数。

### 4.2 拒答闸门的边界（这套数里最该记住的一条）

| 样本 | 重排分 | 说明 |
|---|---|---|
| 正例最低 | **0.551** | 「断路器回路电阻实测值不能超过出厂值的多少倍」 |
| 正例次低 | 0.564 | 「绝缘电阻清洁完还是不合格下一步查什么」 |
| 阈值 | 0.500 | `HybridRetriever.REJECT_THRESHOLD` |
| 否定最高 | **0.419** | 「接地扁铁的镀锌层厚度要求是多少」——被《电力安全工作规程》的接地装置条款误召回 |

分界窗口 **(0.419, 0.551]，宽 0.132**。
语料扩到 180 块后窗口反而比 75 块时（0.046）宽了两倍多：块变多、每块主题变窄，正例更容易被认出来。
但阈值仍是 0.5 这一定值，**换语料或换 reranker 必须重新标定**，不能直接搬。

### 4.3 其它诊断量

| 指标 | 数值 | 说明 |
|---|---|---|
| 重排改写 Top-1 的题数 | 21 / 100 | 重排不是摆设，五分之一的题被它换了第一名 |
| 正例 Top-1 重排分均值 | 0.936 | 与否定类 0.080 拉开一个数量级 |
| 否定类 Top-1 重排分均值 | 0.080 | 30 题无一越过 0.5 |

## 六、这套数怎么用

简历 / 讲稿里可以直接写：

- 自建 15 份规程、180 个知识块的中文语料库，混合检索（向量 + BM25 → RRF → 重排）**Top-3 命中 100%、Top-1 97.1%**；
- **否定类 30 题拒答准确率 100%**，拒答判据建在 Cross-Encoder 重排分上（阈值 0.5），不调大模型即返回，1 秒级；
- 答案正确率 **100%**（人工抽检 30 条，标准：结论对 / 依据对得上来源 / 不编数字）；
- 单次问答平均 **1.5 秒、832 token**；命中缓存后降到 5–7 毫秒。

被追问时要说清楚的三件事：

1. 这套指标衡量的是**这个 180 块小库上的检索与作答质量**，不是通用电力问答能力；
2. Top-3 100% 的原因是语料只有 15 份、主题边界清晰，**难度不在检索而在拒答与跨段**；
3. 阈值 0.5 的实测窗口是 0.132，语料再扩一版就得重新标定，**不能把 0.5 当常数**。

## 七、已知偏差与限制

| 限制 | 说明 |
|---|---|
| 语料是自写模拟规程 | 15 份 md / 180 块，结构与真实电网规程相近，但覆盖面远小于真实资料库；块由二级标题切分，每块 5 句左右 |
| 题库是我按章节出的 | 已换同义词、去掉原文句式，但知识点边界仍比真实提问清晰；真实提问会跨文档、带口语和错别字 |
| 拒答阈值余量有限 | 正例最低 0.551 / 否定最高 0.419，窗口 0.132；换 reranker 或换语料必须重跑标定 |
| 平均响应偏乐观 | 1.47s 是短答案样本；`/diagnose` 多工具链路实测 10~13s |
| token 随语料变长而上升 | 每块从 5 句扩到 12 节后，top5 上下文变长，单次 token 从 660 涨到 832（+26%）；块再大就要考虑压缩上下文 |
| token 只覆盖非流式 | `/chat/stream`、`/chat/mem` 的 usage 在流末帧，未聚合，所以 `/stats` 的 token 只含 `/ask` 与 `/ask-fb` |
| 正确率是单判 | 由一人按三条硬标准判定，没有第二人复核；跨段题在「答得全不全」上有主观余地 |
